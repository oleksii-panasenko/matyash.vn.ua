# matyash.vn.ua

Персональний сайт Ольги Іванівни Матяш, доктора педагогічних наук, професора кафедри алгебри і методики навчання математики ВДПУ імені Михайла Коцюбинського.

Сайт статичний, зібраний на [Astro](https://astro.build). У ньому немає бази даних, PHP чи адмінки, тож на сервері нічого зламати.

## Де лежить текст

| Що | Файл |
| --- | --- |
| Головна (активність, нагороди, школа, фото, контакти) | `src/content/pages/index.md` |
| Наукові публікації | `src/content/pages/publications.md` |
| Наукова школа: вступ про керівницю і фото | `src/content/pages/school.md` |
| Учні наукової школи, один файл на людину | `src/content/school/NN-imia.md` |
| На допомогу аспіранту | `src/content/pages/phd-help.md` |
| Конференція та її архів | `src/content/pages/conference.md` |
| Шапка сайту, меню, підвал з контактами | `src/layouts/Base.astro` |
| Ім'я, посада, профілі ORCID/Scopus/Scholar на головній | `src/pages/index.astro` |

Розділ сторінки починається рядком `## Назва розділу`. На широкому екрані такий заголовок стоїть у лівому полі.

### Як додати учня наукової школи

Створіть файл `src/content/school/17-prizvyshche.md`:

```markdown
---
name: "Ім'я По батькові Прізвище"
photo: "prizvyshche"
year: 2026
order: 17
---

У 2026 році під керівництвом МАТЯШ ОЛЬГИ ІВАНІВНИ захистила дисертацію на тему «…».
```

Фото покладіть двічі, у `public/img/prizvyshche.webp` (повне) і `public/img/thumbs/prizvyshche.webp` (400×500). `year` можна не вказувати.

### Як додати фото в галерею

Усередині блоку `<div class="gallery">` додайте рядок:

```markdown
  [![](/img/thumbs/nazva.webp)](/img/nazva.webp)
```

### Стрічка фото і малюнки в шапках

Три фото під шапкою головної задано списком `band` у `src/pages/index.astro`. Їхні зменшені копії (900×640) лежать у `public/img/band/`. Геометричні побудови в шапках сторінок намальовано в `src/components/PageFigure.astro`.

## Команди

Потрібен Node.js 22.23.4 або новіший (див. `.nvmrc`).

| Команда | Що робить |
| --- | --- |
| `npm run dev` | локальний перегляд з автооновленням: http://localhost:4321 |
| `npm run build` | збирає сайт у `dist/` і перевіряє, що в ньому немає спаму, PHP і зовнішніх скриптів |
| `npm run preview` | показує зібраний сайт |

Після кожного push у `main` GitHub Actions збирає сайт і викладає його на GitHub Pages (`.github/workflows/deploy.yml`).

## Звідки взявся контент

Контент одноразово імпортовано зі старого WordPress (листопад 2026) скриптом `scripts/import-live.mjs`. Скрипт бере сторінки через REST API, розгортає посилання bit.ly і перекодовує фото у WebP. **Не запускайте його повторно:** він перезапише файли в `src/content/`, а після імпорту їх правили вручну.

Старі адреси `/ua/...` переадресовуються на нові (див. `astro.config.mjs`).
